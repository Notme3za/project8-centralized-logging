# GitHub workflow

This repository is public at https://github.com/Notme3za/project8-centralized-logging.

To start from the published version, clone it:

```bash
git clone https://github.com/Notme3za/project8-centralized-logging.git
cd project8-centralized-logging
```

After making changes:

```bash
git add README.md detect_ssh_failures.py rsyslog/
git commit -m "Describe the change"
git push
```

Authenticate through Git's configured credential manager or browser sign-in. Never put a password or access token in the remote URL or commit one to the repository.
